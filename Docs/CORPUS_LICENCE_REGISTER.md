# Corpus licence register

One row per source the project collects, evaluates on, or runs, with the licence as established
on the date given. This is plan box P3-B, rule R9. `lexhybrid/data/corpus/licences.py` holds the licence ids in code.
`build_corpus` (`lexhybrid/data/corpus/build.py`) refuses any document whose licence is `unknown` or unregistered, or whose flags claim more than its licence allows.

A source enters a **shippable** (`commercial_safe`) training arm only if its licence permits commercial use. `research_only` sources enter the research-exception arm only (decision 2). No checkpoint trained on them leaves the cluster (R9, P10).

Licences were verified on **2026-09-27** against the sources' own pages, which are linked in the notes. A row marked *to confirm* has a licence established by statute but not restated by the publisher. It stays in the register with that caveat; it does not upgrade silently.
